# 10 页面清单

设计稿：https://claude.ai/artifact/6E413CWL7EMq59NYC8qn44 （“界面”页是可点击原型，“系统流程”页是 8 张流程图）。

顶栏：对话 · 办公室 · 任务 · 员工 · 员工模板 · 节点 · 审批 · Git 连接 · MCP 接入 · 项目设置；左侧是当前项目切换（进入项目列表）。

| 页面 | 设计稿文件 | 作用 | 主要数据 / 接口 | 里程碑 |
| --- | --- | --- | --- | --- |
| 项目对话 | Chat | 和统筹对话；计划卡片、派发、工作动态、对话内审批；右侧代码存档点、计划进度、参与员工、交付 | messages、plans、tasks、requests；WS `project:<id>` | M3 |
| 项目列表 / 新建项目 | Projects | 项目卡片；新建时选仓库、启用模板、计划是否需确认 | projects、repositories、employee_templates | M1 |
| 办公室 | Main | 按状态把员工画在各区域；点人看详情；右侧项目概况、通道、额度、事件流 | employees、sessions、runtimes、events；WS | M4 |
| 员工列表 | Employees | 按状态筛选；扫描到未登记的员工目录时提示 | employees | M1 |
| 员工详情 | EmployeeDetail | 当前任务、时间线（含子代理）、发消息、历史会话、配置、记忆 · 交接 | sessions、events、memories、handoffs | M2 / M3 |
| 添加员工 | EmployeeNew | 基于模板在某节点上单独加一个员工 | employee_templates、nodes | M1 |
| 员工模板 | Templates | 四种身份说明；模板列表和编辑 | employee_templates | M1 |
| 节点 | Nodes | 节点状态、资源、运行时（版本 / 登录 / 额度 / 槽位）、员工目录 | nodes、runtimes | M1 |
| 添加节点 | NodeAdd | SSH 或安装命令 → 安装进度 → 扫描结果和槽位设置 | node_registrations、runtimes | M1 |
| 任务 | Tasks | 六列看板；新建任务（点名 / 按身份 / 交给统筹） | tasks | M2 |
| 审批中心 | Approvals | 待处理的权限请求和提问；已处理记录；代答规则 | requests、projects.approval_policy | M2 |
| Git 连接 | GitConnections | GitHub 连接（App 或访问令牌）、可访问的仓库、角色默认权限、令牌签发记录。第一版只有 GitHub | git_connections、credential_issuances | M1 / M2 |
| MCP 接入 | McpAccess | 各客户端安装写法、授权列表、工具清单、员工内部工具 | api_tokens | M4 |
| 项目设置 | ProjectSettings | 代码存档点、交付规则、通道、审批策略、员工配置矩阵和均衡策略、项目知识 | projects、project_*、memories(scope=project) | M1 / M3 |

## 办公室页的映射

| 员工状态 | 位置 |
| --- | --- |
| 统筹、决策身份在工作 | 决策室 |
| 执行、验收身份在工作 | 开发区工位（开发负责人在负责人办公室） |
| 等审批 | 工位 + 举手气泡 |
| 排队 | 等候凳 |
| 受阻 / 出错 | 维修台 |
| 空闲 / 暂停 | 休息区 |
| 离线 | 原地灰显 |

机房里每个机柜是一个节点，灯表示槽位占用，标签显示额度。名牌边框颜色区分 Claude Code / Codex，身体颜色区分模板。
