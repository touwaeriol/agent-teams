# agent-teams

把多台服务器上的 Claude Code、Codex 组织成“员工”，按项目编组协作的 Web 平台。

- 平台上配置员工模板（统筹、决策、执行、验收），项目启用模板并指定每个节点建几个员工；同类员工分布在多个节点上，按剩余额度均衡派活。
- 每个项目有一个项目统筹和一个对话：你只和统筹说话，它写计划、派任务、汇总，要你定的事再转回给你。
- 每台服务器跑一个守护进程，主动连上平台，负责扫描 Claude Code / Codex、建员工目录、启动和监管会话。
- 代码存档在 GitHub 仓库里，Git 授权在平台上配一次，节点不保存长期凭证。
- 提供 MCP 服务：在任何支持 MCP 的客户端里就能建项目、和统筹对话、看进度、答复审批。
