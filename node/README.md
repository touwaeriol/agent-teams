# @agent-teams/node — node daemon (v2)

One process per machine. It dials the console at `<console>/nodes/connect` with the node token,
hosts long-lived Claude Code employees (Agent SDK `query()` with streaming input) and Codex
employees (`codex app-server` JSON-RPC), serves the platform tools to them, runs local git
jobs and fetches short-lived GitHub tokens on demand. It makes no business decisions: the
console decides, the daemon executes and enforces per-session tool limits locally.

Spec: `docs/v2/architecture.md` §3.2, §5.2, §6, §8, §10.3, §10.4 and `docs/v2/protocol.md`
(protocol 2 only; the one-shot cut-over means no protocol-1 mode). Message types come from
`/protocol` (schemas + generated TS); inbound frames are validated with ajv against them.

## Run

```sh
npm ci
npm run build                      # dist/node.mjs (SDK, codex, MCP SDK external)
node dist/node.mjs run --console https://console.example --token … --root ~/.agents_team --state ~/.local/state/agent-teams
```

Defaults come from `~/.config/agent-teams/node.env` (written by `install-node.sh`, same keys as
v1): `AGENT_TEAMS_CONSOLE`, `AGENT_TEAMS_NODE_TOKEN`, `AGENT_TEAMS_ROOT`, `AGENT_TEAMS_MAX_RUNS`
(→ `max_active_sessions`), optional `AGENT_TEAMS_STATE`, `AGENT_TEAMS_PASS_ENV`. Flags beat the
process environment, which beats `node.env`. Exit code 75 after a successful `node.upgrade`
(systemd restarts into the new `current` symlink).

`npm run pack` writes `dist/agent-teams-node-<version>.tgz` (node.mjs + package.json with the
exact external versions + npm-shrinkwrap.json); nodes install it with `npm ci --omit=dev`.

## Layout

| Path | What |
| --- | --- |
| `src/link/` | `client.ts` WebSocket link (hello/welcome, 20 s ping / 45 s dead, 1→30 s ±20 % backoff, close codes 4401/1008/4409/4426/4429, cumulative ACKs every 200 ms or 50 commands); `outbox.ts` reliable frames in `state/outbox/<epoch>.jsonl` + `cursor.json`; `inbox.ts` `done.jsonl` (48 h idempotency table), `received.jsonl`, `acked.json`; `dispatcher.ts` dedup + per-session lanes |
| `src/sessions/` | `manager.ts` logical sessions: open / release / send / interrupt / set_mode / close / watch, parking after `park_after_s`, `max_active_sessions` slots (parks the oldest idle session or queues), crash restart 5/15/45 s, `state/sessions/*.json`; `policy.ts` PreToolUse rules (coordinator: platform tools only; read-only: argv Bash allow list, file tools inside cwd + shared `.git`; fixed deny list for node secrets); `env.ts` per-item session env (never `AGENT_TEAMS_*`) |
| `src/sessions/claude/` | Agent SDK driver: `settingSources: []`, explicit `permissionMode`, `strictMcpConfig` + `disableClaudeAiConnectors`, in-process `platform` MCP server, `canUseTool` → `approval.request`, `allow_always` suggestions rewritten to `destination: session`, hooks → `session.event`, SDK `sessionId`/`resume`, msg_id → UUID for transcript dedup after restarts |
| `src/sessions/codex/` | one `codex app-server` per node (`hub.ts`), a thread per employee (`driver.ts`): `thread/start`/`thread/resume` with a fresh `mcp_servers.platform` URL, `turn/start`, `turn/steer`, `later` queued to `turn/completed`, `turn/interrupt`, approvals (command, file change, permissions, MCP elicitation) → `approval.request`, `serverRequest/resolved` → `approval.cancel` |
| `src/codex-protocol/` | generated by `npm run gen:codex` (`codex app-server generate-ts`, CLI 0.169.0) |
| `src/toolhost/` | `broker.ts` tool.call / tool.result (no timeout, blocking tools can wait for hours); `sdk-server.ts` Claude in-process server; `http-server.ts` 127.0.0.1 streamable-HTTP MCP for Codex at `/mcp/<sid>/<secret>`, re-keyed on every start/resume |
| `src/git/` | `git.prepare` (clone, fetch, `worktree add -B`), `git.status`, `git.push` (refspec must be `HEAD:refs/heads/thread/<no>/<employee>`, one-job token via `GIT_ASKPASS`), `git.cleanup`, `git.purge`; platform `pre-push` hook via `core.hooksPath` |
| `src/cred/` | `cred.request`/`cred.response` broker (10 s retry, memory cache), unix-socket server in `$XDG_RUNTIME_DIR/agent-teams` (0700) checked with a per-session secret, `git-credential` helper and `gh` wrapper subcommands |
| `src/upgrade.ts` | `node.upgrade`: fixed download URL, sha256 + Ed25519 (`~/.config/agent-teams/release.pub`) check, unpack to `node-<v>/`, switch `current` |

## Tests

```sh
npm test            # vitest: fake console over a real WebSocket, fake SDK query, fake codex app-server
npm run typecheck
npm run smoke:claude   # real Claude session with this machine's login (pong, platform tool, park + resume)
npm run smoke:codex    # real codex app-server: initialize, thread/start with the loopback MCP, one turn
npx tsx scripts/check-dist.ts   # the bundled dist/node.mjs against the fake console
```

The fake console validates every frame the daemon sends against `/protocol/schemas`.
